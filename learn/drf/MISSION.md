# Mission: Sistema de inventario con Django y Django REST Framework

## Why
Construir una API de inventario útil para gestionar productos, proveedores y movimientos de existencias. El proyecto dará una razón concreta para aprender Django y después exponer esa lógica mediante Django REST Framework.

## Success looks like
- Crear y administrar productos, categorías y proveedores desde Django.
- Registrar entradas y salidas y calcular existencias correctamente.
- Consumir una API autenticada con permisos, filtros, búsqueda y paginación.
- Probar y documentar los endpoints principales.

## Constraints
- Avanzar en lecciones cortas y prácticas.
- Usar documentación oficial como fuente principal.
- Empezar con una configuración local sencilla y aumentar la complejidad gradualmente.

## Out of scope
- Construir todavía una interfaz frontend separada.
- Desplegar a producción antes de dominar el flujo local.
