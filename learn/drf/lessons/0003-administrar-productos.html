Administrar productos

Comprueba el modelo desde la interfaz que Django genera para el personal administrador.

Por qué existe el admin

Django incluye un sitio administrativo para que el equipo gestione datos internos sin que tengamos que construir todavía una interfaz completa. El admin lee los modelos registrados y genera formularios usando sus tipos y restricciones.

Registrar el modelo

Abre catalogo/admin.py y añade:

from django.contrib import admin
from .models import Producto

admin.site.register(Producto)

El registro conecta Producto con el panel. No crea otra tabla; solo añade una interfaz para trabajar con la tabla existente.

Crear un administrador

py manage.py createsuperuser

El comando te pedirá nombre de usuario, correo y contraseña. Luego inicia el servidor con py manage.py runserver y visita http://127.0.0.1:8000/admin/.

Práctica

Crea dos productos desde el panel: uno con color y descripción, y otro dejando esos campos vacíos. Observa qué campos aparecen como obligatorios y verifica que ambos registros se guarden.
