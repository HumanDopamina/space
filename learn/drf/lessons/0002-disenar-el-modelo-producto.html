Lección 2 · Sistema de inventario

Diseñar el modelo Producto

Antes de escribir clases, convierte una necesidad del negocio en datos que Django pueda guardar.

Qué es un modelo

Un modelo es una clase Python que describe una entidad persistente. Cada atributo de campo se convierte en una columna de la tabla y Django usa esa misma definición para validar datos, crear migraciones y ofrecer una API de consultas.

Por ejemplo, un producto puede tener un nombre textual, un precio decimal y una cantidad entera. El modelo expresa qué significa cada dato y qué restricciones debe cumplir.

Flujo mental: requisito del negocio → modelo en models.py → makemigrations crea una propuesta de cambio → migrate aplica ese cambio a la base de datos.

Diseño antes del código

Para este primer paso no añadiremos todavía categorías, proveedores ni movimientos. Aislamos una sola entidad para que puedas ver la relación entre un requisito y un campo.

Un inventario necesita identificar el producto, describirlo, saber cuánto cuesta y conocer cuántas unidades hay disponibles. Django ofrece tipos distintos porque el tipo también comunica reglas: CharField para texto corto, DecimalField para dinero y IntegerField para cantidades.

Ejercicio de diseño

Sin escribir código todavía, propón una tabla para Producto. Para cada campo indica: nombre, tipo de dato y por qué lo necesita el negocio. Incluye al menos cuatro campos y decide cuál debería ser obligatorio.

Ejemplo de formato:

- nombre — texto corto — identifica el producto
- precio — decimal — representa el precio
- ...

Cuando respondas, revisaremos tus decisiones y escribiremos juntos catalogo/models.py.
