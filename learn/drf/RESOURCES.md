# Django y Django REST Framework Resources

## Knowledge

- [Django: Writing your first Django app](https://docs.djangoproject.com/en/6.2/intro/tutorial01/)
  Tutorial oficial para crear un proyecto, distinguir proyecto de aplicación y responder a solicitudes. Usar al comenzar la estructura del sistema.
- [Django: Models and the admin site](https://docs.djangoproject.com/en/6.0/intro/tutorial02/)
  Explica modelos, migraciones, base de datos y el sitio de administración. Usar al diseñar productos y categorías.
- [Django REST framework: Quickstart](https://www.django-rest-framework.org/tutorial/quickstart/)
  Guía oficial para configurar DRF, serializadores, viewsets, routers y autenticación. Usar al convertir el inventario en API.
- [Django REST framework: Authentication and permissions](https://www.django-rest-framework.org/tutorial/4-authentication-and-permissions/)
  Tutorial oficial para proteger endpoints y controlar quién puede operar sobre los datos.
- [Django REST framework: Testing](https://www.django-rest-framework.org/api-guide/testing/)
  Referencia oficial para probar endpoints con las herramientas de DRF.

## Wisdom

- [Django Forum](https://forum.djangoproject.com/)
  Comunidad oficial para preguntas y decisiones de diseño de Django.
- [Django REST framework discussions](https://github.com/encode/django-rest-framework/discussions)
  Espacio de discusión del proyecto para dudas específicas de DRF.
