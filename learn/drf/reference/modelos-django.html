Modelos Django

Una guía rápida para convertir entidades del inventario en tablas.

Campos del Producto

class Producto(models.Model):
    name = models.CharField(max_length=150)
    price = models.DecimalField(max_digits=10, decimal_places=2)
    description = models.TextField(blank=True)
    color = models.CharField(max_length=50, blank=True)
    # id se crea automáticamente

Reglas rápidas

  • CharField necesita max_length.
  • DecimalField necesita max_digits y decimal_places; es adecuado para precios.
  • blank=True permite dejar el campo vacío en formularios y validación.
  • null=True permite guardar SQL NULL; para texto normalmente se prefiere solo blank=True.
  • Django agrega un id como clave primaria si no declaras otra.
